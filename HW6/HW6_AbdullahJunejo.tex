\subsection{Count of records for each prizes.category in descending order of count.}
\begin{lstlisting}
db.laureate.aggregate([
    {
        $unwind: "$prizes"
    },
    {
        $group: {
            _id: "$prizes.category",
            count: { $sum: 1 }
        }
    },
    {
        $sort: {
            count: -1
        }
    }
])
\end{lstlisting}
The query deconstructs the `prizes` array for each record, groups by the `category` field within the `prizes` subdocument, and sorts the results in descending order based on the count.

\subsection{Count of records for each gender, diedCountryCode, prize.category when prize.category is “physics”. Order the output by diedCountryCode.}
\begin{lstlisting}
db.laureate.aggregate([
    {
        $unwind: "$prizes"
    },
    {
